Comandos de Kiro

Explora las herramientas que Kiro ofrece para ayudarte a construir y administrar tu comunidad.

🛡️ Moderación

/ban
Banea permanentemente a un usuario del servidor.
/unban
Revoca el baneo de un miembro usando su ID.
/kick
Expulsa a un usuario sin borrar su historial.
/mute
Aisla al usuario con el sistema nativo de Discord, bloqueándole el chat y voz automáticamente.
/unmute
Le quita el aislamiento a un miembro antes de tiempo.
/clear
Elimina una cantidad específica de mensajes del chat.
/warn
Le da una advertencia al usuario y la guarda en la base de datos.

💰 Economía

/balance
Consulta tu saldo.
/daily
Reclama tu recompensa diaria.
/work
Trabaja para conseguir dinero.
/pay
Envía dinero a otro miembro.

🎫 Tickets

/close
Cierra el soporte actual.
/staff
Revisa el equipo actual de soporte.

ℹ️ Información

/help
Muestra la ayuda de Kiro.
/botinfo
Muestra información sobre Kiro.
/serverinfo
Muestra información del servidor.
/userinfo
Muestra información de un usuario.

🎮 Diversión

/8ball
Pregunta algo y deja que Kiro responda.
/coinflip
Lanza una moneda.

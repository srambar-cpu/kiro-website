Documentación de Kiro

Aprende a utilizar y configurar las diferentes funciones de Kiro para tu servidor de Discord.

🐱 ¿Qué es Kiro?

Kiro es un bot multifunción para Discord diseñado para ayudar a las comunidades a administrar, organizar y entretener a sus miembros.

Puedes utilizar sus sistemas de moderación, economía, tickets, logs, diversión y mucho más.

🛡️ Moderación

Herramientas para ayudar al equipo de moderación a administrar el servidor.

/warn — Advertir a un usuario.
/mute — Silenciar temporalmente a un usuario.
/kick — Expulsar a un usuario.
/ban — Banear a un usuario.

💰 Economía

Sistema económico para crear una economía dentro de tu comunidad.

/balance — Consultar tu dinero.
/daily — Reclamar tu recompensa diaria.
/work — Trabajar para obtener dinero.
/pay — Enviar dinero a otro usuario.

🎫 Tickets

Sistema de soporte para que los miembros puedan contactar con el equipo del servidor.

/ticket — Crear un ticket.
/ticket-panel — Crear un panel de tickets.

ℹ️ Información

Consulta información sobre Kiro, el servidor y los usuarios.

/help — Mostrar ayuda y comandos.
/botinfo — Información sobre Kiro.
/serverinfo — Información del servidor.
/userinfo — Información de un usuario.

🎮 Diversión

Funciones para entretener a los miembros de tu comunidad.

/8ball — Pregunta al 8-ball.
/coinflip — Lanza una moneda.

⚙️ Configuración

Kiro está diseñado para que cada servidor pueda configurar sus funciones según sus propias necesidades.

Próximamente se añadirán más opciones de configuración y sistemas.

Política de privacidad

Información general sobre el tratamiento de datos relacionado con el uso de Kiro.

Última actualización: septiembre de 2026

1. Introducción

Kiro es un bot multifunción para Discord. Esta política explica de forma general cómo puede manejarse la información necesaria para proporcionar sus funciones.

La política podrá actualizarse a medida que Kiro incorpore nuevas funciones.

2. Información que puede utilizar Kiro

Dependiendo de las funciones utilizadas y de la configuración de cada servidor, Kiro puede necesitar utilizar determinados datos proporcionados por Discord para ejecutar sus funciones.

Entre ellos pueden encontrarse identificadores técnicos de Discord, como identificadores de usuarios, servidores, canales o roles, cuando sean necesarios para una función determinada.

Kiro no necesita conocer información personal como contraseñas de Discord para funcionar.

3. Uso de la información

La información utilizada por Kiro puede emplearse para proporcionar, mantener y mejorar las funciones del bot.

Por ejemplo, determinadas funciones pueden necesitar identificar un usuario o servidor para saber dónde ejecutar una acción o guardar una configuración.

4. Configuración del servidor

Algunas funciones de Kiro pueden requerir guardar configuraciones específicas de cada servidor.

Estas configuraciones podrían incluir información necesaria para determinar canales, roles, permisos o preferencias de funcionamiento del bot.

5. Datos económicos y sistemas internos

Si Kiro ofrece sistemas como economía, niveles, inventarios u otras funciones que necesiten información persistente, los datos necesarios podrán almacenarse para que dichas funciones puedan funcionar correctamente.

Los detalles específicos de cada sistema se definirán y documentarán cuando esas funciones sean implementadas.

6. Tickets y soporte

Si Kiro incorpora sistemas de tickets, determinados mensajes o información relacionada con un ticket podrían ser procesados para permitir el funcionamiento del sistema de soporte.

La información específica que se conserve dependerá de cómo se implemente finalmente el sistema.

7. Compartición de información

Kiro no está diseñado para vender información personal de los usuarios.

Cuando una función requiera utilizar servicios externos, se informará de ello cuando corresponda.

8. Seguridad

Se procurarán aplicar medidas razonables para proteger la información utilizada por Kiro.

Sin embargo, ningún sistema conectado a Internet puede garantizar una seguridad absoluta.

9. Discord

Kiro funciona dentro de Discord y depende de los servicios proporcionados por Discord.

El uso de Discord también está sujeto a las políticas y condiciones establecidas por Discord.

10. Cambios en esta política

Esta política puede actualizarse cuando Kiro incorpore nuevas funciones o cambie la forma en que maneja la información.

La fecha situada al principio de esta página indica cuándo se realizó la última actualización.

11. Contacto

Cuando Kiro disponga de un canal oficial de contacto relacionado con privacidad, la información correspondiente será publicada en el sitio web oficial.
